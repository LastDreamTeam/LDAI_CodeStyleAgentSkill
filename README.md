# LDCodeStyleAgentSkill

**`ld-codestyle-online` —— LD 人类与 Agent 协作编程技能的 GitHub 持续更新版。**

LD = **LastDream · 最后的梦**。官网：[lastdream.net](https://lastdream.net)；B站：**最后的梦制作组**。

## 为什么做这个技能

我们希望探索一种更适合未来人类与 **Agent / SuperAI** 配合开发的方式：人类仍然可以通过熟悉的 **Markdown、自然语言、接口与必要的代码**，具体地表达自己的欲望、创意、设计与边界；Agent 则承担更多细节实现、验证和日常维护。

这不是让人类彻底无视代码，也不是把设计权交给黑箱。人类把重心更多放在“想要什么、为何需要、最终体验应该怎样”，同时保留理解、查看、调整和约束实现的入口。我们希望成果既能运行，也能被人读懂、接管和继续演进。

本技能将这种分工落实为可执行的工程约定：小而清楚的控制接口、可替换实现、就近的 Markdown 模块说明、可追溯注释归属，以及包含真实 Bot / 模型身份、问题和解决方式的提交记录。**这些约定服务于协作，不以制造更多抽象层、文档或审批为目的。**

## 当前阶段与适用范围

目前仍处于**持续迭代、研究与工程实践阶段，主要服务内部重型开发**。公开是有限度地分享方法和工具，促进更好的协作，而不是宣称已经形成适用于所有项目的普遍标准。

- **主要面向 Unity 等重型开发。**Unity 工程已经采用 LD 约定，或用户明确要求采用时，才应用对应治理规则；安装技能并不意味着接管所有 Unity 工程。
- **其他类型项目不强制、不直接启用。**必须由用户明确要求 Agent 使用此技能，再确认语言和项目是否适合面向对象、接口/抽象层、可替换实现等特性。按实际适用范围裁剪，不把 Unity 目录、生命周期或 Inspector 规则硬套到别的技术栈。
- 第三方插件、生成文件、序列化资产和现有公共契约有独立边界。技能不是改写它们的授权，也不能覆盖当前任务范围。
- 原 `ld-codestyle-v6` 是首版的规范来源；在线版拥有自己的版本号。**同一任务只使用一份确定版本，不叠加旧版与在线版。**

## 安装

### Hermes：优先原生技能管理

```sh
hermes skills install LastDreamTeam/LDCodeStyleAgentSkill/skills/ld-codestyle-online
```

遵循 Hermes 自身的扫描、确认和 profile 选择流程，不使用跳过安全检查或强制覆盖参数。**当前 Hermes 扫描器会将本技能的原生更新命令执行、子进程环境传递标为 CAUTION；新社区来源可能因此被拦截。**若被拦截，保留扫描结果并交由使用者按其平台的正式信任/审批流程处理，Agent 不自行绕过；本仓库不能承诺该命令在所有 Hermes 版本无确认安装。安装后明确告诉 Agent 在目标工程使用 `ld-codestyle-online`。

### 其他支持 SKILL.md 的终端 / Agent

先核该产品当前的技能安装入口；本仓库不假定 Grok CLI、Codex CLI、Codex Desktop 的目录约定完全相同。推荐每个独立技能安装实例使用**独立克隆**，将下列子目录通过产品支持的本地技能入口接入：

```sh
git clone https://github.com/LastDreamTeam/LDCodeStyleAgentSkill.git
# 技能目录：LDCodeStyleAgentSkill/skills/ld-codestyle-online
```

手工只复制 `SKILL.md` 会丢失配套规范与脚本；请安装整个技能目录。若多个终端故意接入同一个真实目录，它们就是共享安装，不是隔离副本；不同版本请用不同克隆路径。未提供该终端的接入/调度验证时，不宣称已经适配。

## 更新与本地配置

默认**每 7 天检查一次**，使用普通 Python 脚本检查版本，不调用模型 API。首次使用会检查；未满周期不访问网络。Agent 在调用技能时触发检查，在没有任务占用的安全边界进行更新，随后重新读取技能。

**技能不是常驻服务。**不使用时不会凭空在后台运行，也不会自行安装 cron 或系统任务。若希望即使不开 Agent 也定期维护，可由终端已有调度机制运行同一脚本；调度权限与任务占用协调仍由使用方负责。

本地数据包括人类名/注释标记（默认 `LD`）、检查间隔、上次尝试与成功时间等。选择顺序：

1. 调用方明确提供 `--data-root`（终端为技能分配的数据根目录）；
2. 可选的 `LD_CODESTYLE_DATA_ROOT` 环境变量；
3. 能确认所属 Hermes 安装时，使用该 profile 的 `skill-data`；
4. 其他情况退回技能自身的 `.ld-codestyle-data` 子目录。

前三种共享根下仍按**技能真实安装路径的标识**分隔，各终端、各克隆、各版本安装副本不会共用一个配置文件。原地升级保留同一实例的偏好；数据格式有独立 schema 版本。环境变量是覆盖入口，不是要求设置的全机公共状态。

更新不修改人类名，不批量替换源码注释，不更改人格、记忆、凭据或业务项目。修改人类名只改变后续识别约定；原有 `LD:` 和既有人工注释继续保护，原版权来源不得因此被抹去。详细命令与边界见[安装、配置和更新](skills/ld-codestyle-online/references/maintenance.md)。
