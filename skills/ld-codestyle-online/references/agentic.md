# Agentic.md：模块索引，不是更高权限

`Agentic.md` 是 AI 维护、面向人类也可读的模块地图和工作缓存。当前人类指令、工程规则、真实代码/接口/序列化契约优先；索引过时不能反过来修改代码来迎合它。

目录级 README 与 `Agentic/MEMORY.md`、`Agentic/USER.md`、`Agentic/DEBUG.md` 另见[共享上下文规范](directory-context.md)。`Agentic.md` 索引不等于 `Agentic/` 记忆存放目录；索引保留既有位置与职责，指向各区域README声明，不吸收兄弟模块记忆正文。README声明逻辑区域和入口，MEMORY存经验，USER存意图，DEBUG存用户操作/测试流程；这些记忆的范围与其所属README同级，不因物理存放而只管Agentic。一个事实只维护一个有效正文，其余用路径索引；不自动迁移/合并/删改历史人类文档。

## 放在哪里

在已采用规范的一方 Core 根（如 `Assets/Core` 或 `Assets/LastDream/Core`）和有意义的类别/模块目录放索引。从根到目标模块顺序读取，再核对相关真实源码。

普通结构叶子目录如 `Scripts`、`Agentic`、`Editor`、`Resources`、`Prefabs`、`Scenes`、`Textures`、`Sample` 不重复铺索引，除非本身是独立的大模块。第三方、Packages、生成/导入/缓存目录不自动添加。

## 何时维护

授权写任务中，只更新实际触及且责任、入口、契约、依赖、资源、生命周期、验证、子模块地图或风险确实变化的索引；缺少的相关模块索引可以补建。只读查询时不创建或修改。不要为刷新日期、记录聊天流水而重写。

保护既有 `.meta` 标识；新增资产由 Unity 正式导入流程生成 `.meta`。模块迁移同步父子链接，并单独验 namespace、asmdef 和序列化兼容。

## 精简模板

```markdown
# <模块名> Agentic 索引

<真实提供方>: 文件说明（先读）：本文件是本模块的持久共享索引，供人类与不同Agent接续使用，不是临时文件、任意日志或宿主私有记忆。即使未安装本技能、不在舰队或指挥系统，也请保留其索引职责，不得擅自删除或改作他用；不等于Agentic/目录，不自动迁移。

逻辑作用域：<真实模块路径及排除项>；所属README入口：<实际相对路径或明确未建立>。修改本模块前先读适用索引和区域记忆，核来源及真实代码；仅在当前任务授权内更新真实增量，保留有效正文，简记日期、变更原因与实际模型身份（仅私有目标；公开省略身份，见变更记录）。不高于当前用户指令、系统安全边界或真实序列化契约，不因索引扩大权限。

维护权限：普通Agent仅在九成以上把握时去除明显重复或无损整合，否则不动；内容压缩限专门获授权的审计/辅助模型，保留独立信息、条件与来源。

创建日期：<真实日期或历史未知>；最近修改日期：<本次实际日期/时区>。

## 目录与子模块索引

## 已知限制与未验证范围
## 变更记录
日期：<真实日期>；动作：<新增/修改/删除>；条目标识：<受影响小节/路径>；摘要/原因：<说明>。
公开目标：只保留非敏感变更记录，不附模型/Bot/客户端/计算机/人类显示名，也不在其他正文补记。未知不默认私有；公开前检查并脱敏文件和待推送历史中的证件号、密钥等隐私，保留合法版权/许可来源。
仅经核私有目标追加：##模型：<真实Bot/客户端名> + <实际模型标识> | <本次索引修改摘要>
```

只保留有内容的章节；父索引做地图，子索引存细节。日期/修改身份遵循共享记忆规范；仅私有目标的本地Agent按Commit规则追加实际计算机名，删除也保留不含敏感原文的简短变更记录。不冒写人类标记，不保存凭据、个人信息、全量日志或臆测进度。
