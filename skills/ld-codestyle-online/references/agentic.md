# README 模块索引与旧 Agentic.md 收敛

**模块地图统一由所属 `README.md` 承担，不再新建或续写 `Agentic.md` 平行索引。**保留 `Agentic/` 实现与记忆目录；宿主 `AGENTS.md` 仍有独立职责，不在替代范围。本文沿用 `references/agentic.md` 路径以兼容技能内的引用，但不再提供旧文件的生成模板；新区域使用 [README 模板](../templates/module-readme.md)。

README 是可核地图，不是更高权限。当前人类指令、工程规则、真实代码/接口/序列化契约优先；索引过时不能反过来修改代码迎合它。它维持业务说明、边界和操作入口，同时声明记忆入口，不能退化成只有链接的空壳。详细层级与按需读取见 [共享上下文规范](directory-context.md#记在哪里)。

## 放在哪里与何时维护

在已采用规范的一方 Core 根和有独立责任的模块区域使用现有 README；目录不必叫 Core 或 Base。README 可以与所说明的模块目录同级，明确列出所管区域、记忆真实路径和排除项，不能把物理父目录直接当逻辑范围。

平时从所属 README 读取相关记忆和直接依赖，记录也放本区域；平时，一条坑记在出事那块目录自己的 README/Agentic 里。**致命级例外优先**：死机、崩溃、掉数据、工程/存档损坏，要往外挪到「凡是动这块东西的人都得先看」的那一份文件（含它的索引）；XR 就是 XR 那套文件里最外面的那一份，不是项目根，也不是只留在出事那个子目录。条目标注「死机级」，带触发条件和一手证据（版本/提交）。普通目录不重复铺空索引，不接管第三方、生成或缓存目录。

授权写任务只维护实际触及、存在真实增量的区域。只读不改，安装/升级技能不等于全仓迁移授权。新增文档由 Unity 正式导入产生 `.meta`，保留已有 GUID；模块本身迁移还须另核 namespace、asmdef 和序列化兼容，不能用文档收敛掩盖代码/资产搬迁。

## 打扫时收拾旧索引

这是不定期的专门动作，不是每次开发都做；搬时留一行“从哪搬到哪、谁搬的”，公开目标按下文隐私规则记录。可以分批，未做完记一句“还差哪些”。

1. **核原入口与所有权**：检查旧 Agentic.md、现有 README/Readme、入链、正文与 Git 脏状态。在本次授权责任区内处理；保护人工内容，不能覆盖同名文件，也不制造只差大小写的路径。
2. **保全后归位**：旧 Agentic.md 中有价值的实际正文进入所属 README 对应小节，包括业务边界、依赖与禁止反向依赖、资源与装配前提、生命周期/数据流/线程/清理及相关经验，不得只搬章节标题或链接。只可省去几乎完全无效且没有价值的无意义内容，拿不准则保留，不因篇幅、模板精简或“深度架构”标签丢失正文。已有独立 USER/MEMORY/DEBUG 仍按其责任范围维护，不复制成第二份长期正文。保留有效正文、来源、日期、条目标识、条件和已有 Unity `.meta` 身份；合并文件时先核引用，不让两个 GUID 随意互换，不把无损搬迁当作压缩授权。
3. **更新实际读取入口**：修正所有受影响的相对链接、父子地图和明确引用旧文件的配置/宿主入口；受保护文件不能改时保留阻断，不绕审批。由旧路径进入、由上层进入、只处理某一关联方时，都应找到同一有效说明。
4. **停用旧正文**：验证接收内容和链接后退役旧 Agentic.md。确需兼容的旧入口只能写新路径、原 scope 和迁移说明，注明剩余引用及退役条件，保持**单一有效正文**；不能让 README 与 Agentic.md 各写一套。无兼容需要时按授权保全后移除旧入口；历史仍可从 Git/备份追溯。
5. **按范围验收**：逐项核有效知识已接收、单条 scope 正确、入链和相对链接可达、无双写、人工内容与 meta 未受损。仅新增 README 不算完成；有冲突或受保护入口未改，在原记录记清还差哪些、为何暂时不能搬。PR 中修规范/模板不等于任何业务项目已完成迁移。

每份实际 README 都须独立说明持久共享属性、逻辑作用域、维护边界、创建日期与最近修改日期，使用 [统一模板](../templates/module-readme.md) 并按真实增量填写变更记录。公开目标只保留非敏感记录，不记录执行身份，也不在其他正文补记；私有目标可按[提交规范](commit.md)保留已核真实来源。公开前还须检查文档及待推送历史的个人/企业隐私，不借迁移把敏感材料重新公开；合法许可来源保留。只保留有内容的章节，父 README 作地图、子 README 留细节，不复制第二套索引模板。保留许可来源与有效历史，不保存凭据、宿主私有记忆、全量排错日志或臆测进度。
