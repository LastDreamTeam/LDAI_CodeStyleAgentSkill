# 交互询问与安全续行

本页是LD协作约定，适用于已经采用本技能且当前宿主允许的任务。不是普遍行业定义、自动提权机制或跨终端控制授权。先看当前用户要求及宿主真实能力；问询界面只收集意图，不替代执行审批。

## 工具类 Agent 与 Bot

- **工具类 Agent**：LD通常指Codex、Cursor、VSCode/VistualStudio(Copilot/OtherAIPlugin)、DeepSeekHarness等依附当前终端/IDE/宿主工作的常驻工具型Agent。名称中的`VistualStudio`沿用原请求拼写，通常所指为Visual Studio。这里的“非跨平台”说的是本次交互范围，不宣称这些产品不能支持多个操作系统、不能有记忆，或只能采用一种部署方式。
- **Bot**：LD指具有较稳定人格/性格/“灵魂”配置、私有长期记忆、聊天职责、私有技能和资料空间、可A2A+Gateway队友通讯，并有自身可操作运行终端的AI队友单元。常见运行环境为Linux等，可长期在线或随时唤醒。“灵魂”描述角色与配置设计，不主张人类意识，也不是权限凭证。
- 用户对Bot运行终端的原始描述是：“具备可操作的非远程运行终端（常见Linux等，非远程与链接其他云端操作且通常24h在线/随时唤醒的设备）”。本页的操作性解释：强调Bot有自身运行和可操作的环境，不只是链接另一台机器代为执行；自身环境可部署在云机，不等于禁止云托管或禁止另行获准的远端工作。
- 按**当前实际角色、宿主和任务**判断，不只凭产品名、是否叫Bot、是否有昵称分类。同一底层模型/产品可承载不同角色；有未具备的能力如实注明。角色不自动升级权限，也不改变[提交身份规则](commit.md#客户端bot-与计算机身份)的机器名要求。

> 角色来源补充：维护者于2026-10-16确认，列克星敦、女仆长是上海 Hermes Bot 队友。此处仅记录角色来源，不赋予项目架构裁决权，也不导入私人运行资料。

## 何时问，在哪里问

1. 先找已有需求、区域USER/MEMORY及真实代码，明确问题是否已解答。普通排错、已授权且低风险的实现细节自主处理，不把每个错误变成弹窗。
2. 有实际业务方向选择、需求冲突、显著返工/影响取舍或需新增许可，且不能根据既有要求可靠决定时再问。不要仅以“我觉得重要”反复确认，更不对明确授权重复设闸。
3. **工具类Agent**优先当前授权终端/宿主的原生询问工具；支持时可采用宿主允许的MCP Elicitation表单。缺少原生能力时才用本技能轻量本机HTML辅助，最后退回同一终端/宿主的文字问询。**不得跨其他电脑、跨平台弹窗，不默认转QQ/微信或另一个终端**。远程执行终端无用户UI时，回当前授权宿主的原有交互面，不自行SSH、端口转发或借另一机器弹窗。
4. **Bot**主要在本次任务相关聊天渠道，用原生问询卡片或直接聊天消息询问；不因自身Linux/云环境能运行浏览器，就在那里开用户看不到的弹窗，也不到用户另一台电脑弹窗。不默认另发一个渠道或同时多处刷消息。
5. 明确无人值守时不启动等待型询问，直接进入下文安全续行判断。工具/宿主没有超时能力时不能以虚构参数假装支持；用其现有取消/异步/文本机制，并说明实际限制，不更改宿主安全配置。

每个问题包含任务/模块、简短问题、少量选项及关键差别、推荐理由、自定义输入、取消/稍后。原生工具的数量限制优先。推荐只标注不预先替用户选择；不抢焦点、不模拟点击替用户回答，同题只保留一个有效请求。原生能力由宿主提供，安装本技能不自动给任何Agent增加宿主工具。

## 没有回答：先评估，任务继续

用户要求：“如果没有回答，Agent也不应该就此中止任务，而是应该考虑能否安全的自行决定”，并指出“如果无法回档和涉及的业务方向多的话就继续其他任务内容待收尾后的结果中询问”。适用于工具类Agent与Bot的已授权任务，不能简化成“超时一律停工”或“超时自动选推荐”。

按下面顺序处理未回答、确认未送达或无人值守的待决项：

1. **检查原授权与依赖**：这项是否本就已获授权？是否需要新的同意？是否依赖另一个尚未裁决的问题？沉默不提供新授权，也不撤销其他明确有效授权。配对接口等架构裁决遵循[协作契约](contract.md#模块结构与控制边界)；当前任务或既有项目授权已明确时无需再次询问，角色/头衔和安全自评不产生该授权。
2. **评估安全自行决定**：能否低风险、可靠回档，现有需求是否足以确定方向，是否不牵动难以裁决的多个业务方向？有依据且全部成立，可自主选择合理方案继续，依据来自既有授权而非未答复。不要求用户为每个可回档小决定重开口。按改动影响核真实调用者、依赖与契约；未知先定向调查，不能只因Git可回档就把未核影响填成低风险。
3. **只暂缓不能安全决定的项**：无法可靠回档、业务方向涉及面大而不能安全裁决、需新增批准或证据不足时，保留问题及可选方案。对用户原句的执行采用保守处理：任一因素已使安全判断不成立即暂缓，而不是必须几个风险同时出现才暂缓；也不把“涉及多个模块”自动等同危险或方向不明。
4. **继续不依赖该决定的其他任务内容**，不得先偷选未定方向做依赖实现再称“只是继续”。只有确实没有其他可安全推进内容时才报告整体受阻；缺一个回答不是自动终止整项任务的理由。
5. **收尾结果集中询问**：交付已完成成果，并列必要的“已自主决定”（依据、回档办法）和“仍待裁决”（范围/影响/选项）。详细记录留任务文件，面向用户只呈现必要摘要；未决项不标完成，不因最后收尾无人回答就伪造结论或无限续等。不重复弹、不定时刷提醒。

最小记录：`待决项 / 判断与实际动作 / 依据 / 是否可回档及回档办法 / 仍待裁决的影响`。回档指真实可恢复路径，不等于一律git reset，不覆盖人工脏内容；外部动作不能仅凭本地Git备份称可回档。

**取消、拒绝、稍后不是沉默**：尊重明确回答，不得按“未答复”选其反方向执行。取消问询不自动取消整个任务；停止了哪项按原意判断，其他明确授权继续。已有授权不受影响，不扩大成“超时后所有外部写入都禁止”。真正危险/不可逆且需本人许可的动作保留门禁，不借可配置选项关闭审批。

## 路径隔离配置与计时

沿用[数据位置与隔离](maintenance.md#数据位置隔离与并发)，即`--data-root` → `LD_CODESTYLE_DATA_ROOT` → 可识别Hermes profile数据目录 → 技能内回退。共享根按**实际技能安装路径**区分实例；这里不是操作系统PATH搜索路径。两个终端若故意共享同一实体安装与数据根，也会共享偏好，需独立时提供独立数据根，不承诺路径摘要自动识别所有机器。

配置保存在同一实例`config.json`的可选`interaction`对象，旧schema-1兼容并保留其他字段；缺值只解析默认，不为了缺新字段丢弃旧配置。`show`显示`config_path`及解析后的`interaction`，不必改源码：

- `enabled`：默认true，允许在有必要且宿主允许时交互；关闭不提供新权限，也不关闭宿主审批。
- `answer_wait_minutes`：默认15，允许1–1440整数分钟；从原生工具或页面确认展示后开始等待回答，不从模型起念或进程启动时计算。
- `idle_after_minutes`：默认0（关闭可选输入空闲判断），允许0–1440整数分钟；与回答等待独立。只有宿主能合法提供**当前用户终端**输入信号时才使用，只调整打扰程度，不推出“确认离开”。当前HTML辅助不监控全局键鼠，始终回报`unsupported_not_observed`，配置不等于检测已经实现。不得拿页面无事件或Bot服务器空闲代替用户终端活动。

用户明确“这题等我几分钟”可覆盖该请求的回答等待，不改长期偏好；辅助回执的`answer_wait_source`区分`default`、`config`、`override`，同时显示实际配置路径与有效值。持久参数修改命令集中在[README参数设置](https://github.com/LastDreamTeam/LDAI_CodeStyleAgentSkill#参数设置)，修改后读回；数值含义、范围和真实配置位置可见，损坏配置报错而非重置。宿主原生等待上限不能被技能强行改写，实际有效限制须说明。

投递/打开阶段也有有限上限：本机辅助默认60秒，可通过该次调用的`--delivery-seconds`在1–300秒内调整；没有显示确认记`undelivered`，不记用户十五分钟未答。页面确认可见只证明展示回执，不证明用户读过。窗口关闭无有效动作时保留未回答/超时，不等于同意；显式“取消/稍后”分别回传。

## 本机 HTML 辅助

[脚本](../scripts/interact.py)只用Python 3.10+标准库；[页面](../assets/question.html)与[脚本](../assets/question.js)随技能提供，无CDN、无需安装依赖。仅供已核实当前授权用户终端的工具类Agent、原生问询不可用时使用；Bot、无人值守、关闭交互、原生可用或未确认本机UI时返回原因，不起监听、不打开浏览器。

先按[请求示例](../templates/question.example.json)在本任务私有目录写真实问题。`request_id`、`session_id`和`revision`须绑定当前任务，示例值不是生产身份；问题实质变化改revision，已失效请求不可复用答案。同题同会话持有单独排他锁，不锁住其他任务；过期、错会话、错修订、重复答案都拒绝。多个普通任务仍由宿主协调，不借此并发写同一业务现场。

工具类Agent在**当前本机终端**通过终端工具执行：

```sh
python -B scripts/interact.py --data-root "<同一实际数据根>" --actor tool-agent --local-ui-allowed --question "<本任务问题.json>" --open-browser
```

`--local-ui-allowed`是调用方已经核定当前终端/能力/权限的声明，不是绕过审批的开关。使用背景执行/结果回收支持时，可在等待期间推进独立工作；不用长时间占用唯一聊天入口。没有本地桌面就走原宿主文字，不安装GUI、不跨机补桌面。

脚本首先输出当前本机临时URL（token在fragment），只可交本终端浏览器，不发其他渠道、不写公开日志；可读该调用日志的人能使用此token，不将stdout当公开审计流。默认不自动开浏览器，`--open-browser`调用当前环境的浏览器入口；是否指向远端DISPLAY/BROWSER或会抢焦点须由调用方先核，不能从命令启动成功证明弹在正确终端。不能保证不抢焦点时不用该开关，只在当前宿主提供链接；不模拟回答。服务绑定`127.0.0.1`随机端口，只开放固定页面/JSON端点，要求精确Host/Origin、随机token和问题身份，无目录读取或选项命令执行。能力令牌防跨站猜测，不是对同机恶意进程的强隔离；不要收密码/密钥/支付凭据。

之后输出唯一终态JSON，并带`decision`与`required_record`。`user_approved:false`表示辅助**不签发执行许可**，不抹去用户真实提交的答案；Agent结合答案及原审批体系判断下一步。

| outcome | decision及含义 |
|---|---|
| `submitted` | `review_explicit_answer`：核当前答案及原审批，不自动执行。 |
| `cancelled` / `deferred`（宿主还有`declined`） | `respect_explicit_response`：尊重人类明确取消/稍后/拒绝，不按沉默反向执行。 |
| `timed_out` / `undelivered` / `unattended` / `disabled` | 无评估材料时为`assessment_required`；材料齐全时按安全判断返回`safe_self_decision`或`defer_item_continue_independent`。 |
| `channel_required` / `native_required` / `local_ui_not_allowed` | `routed_not_assessed`：应走原聊天/原生/同宿主文字；不是用户未回答，不提前作超时续行判断。 |
| `aborted` | `reconcile_caller_abort`：调用方中断，核原因与原结果，不冒充用户取消。 |
| `question_locked` / `error` | `reconcile_tool_state`：锁冲突/工具故障不是用户未答，先核原进程、原结果或使用正常文本回退。 |

可选`--assessment "<本任务评估.json>"`使上述判断可通过真实CLI调用并回传记录。评估文件在提问前解析；不存在、身份不符、缺字段、非法类型或超过16 KiB时返回`error`，本次不启动弹窗，先修正材料或在原宿主处理，不能将错误当用户未答。JSON必须含与问题一致的`request_id/session_id/revision`、六个显式布尔字段`authorized/reversible/direction_clear/low_risk/needs_new_approval/depends_on_pending`以及非空`basis/rollback_method`。这些是Agent核原授权、回档办法与业务影响后的**自评及依据**，不是用户签名或机器认证。安全自主要求前四项true、后两项false；不能为了过判断乱填true，不可回档就明确false并说明。辅助只分流、不执行动作。

未提供评估材料时仍正常收答案，非应答结果返回“需评估”而非默认停工；Agent可在退出后按本页规则自行评估并记录，也可在已明确无人值守的原请求上带真实评估文件验证分流，不能为补判断重开一个弹窗。执行前复核评估仍适用，等待期间目标/现场变更就重评；保留实际动作与未决事项供收尾交付。

回答/超时/取消/可捕获的调用方中断后关闭本次监听；无定时提醒、无常驻服务。请求与答案仅进本次调用输出，不写跨会话记忆。异常退出残留锁与仍在执行的同题均返回`question_locked`，**不猜锁已过期、不自动抢锁**；先核锁中PID/原问题与原结果，再处理真实残留。SIGKILL等无法捕获的强杀不承诺留下终态；重试先回读原结果。晚到回答检查问题是否仍适用，不覆盖已经自主完成或已被新需求替代的决策。Windows原生表单不在首版，待出现HTML实际无法覆盖的场景再单独评估。

## 验收与已知限制

- 真实配置CLI核默认、旧值保全、路径隔离、非法值拒绝及单次覆盖不落长期配置。
- 核可逆安全自主、难回档/多方向/新增许可仅暂缓该项、明确取消/拒绝不按沉默处理、收尾不冒报完成。
- 真实本地HTTP/CLI测试选项与自定义回传、取消/稍后/超时/未展示、并行错token/会话/修订/重复晚答、Host/Origin与输入限制；退出后监听关闭。
- 原生IDE/聊天界面由各宿主提供，需逐环境验证。Python协议通过不是Windows/macOS原生UI、浏览器视觉/焦点行为或业务工程验收；也不是已启用全局空闲检测。无浏览器实测必须明示，不能伪造截图或声称全部终端已适配。
